## 📊 90분 In-Class Workshop 진행

### 강의 (20분): Discussion의 전략적 설계

## 1. Discussion의 전략적 설계: 3-Level Claim Hierarchy

### 1.1 핵심 원리: Inference Gap Theory

Discussion 섹션의 핵심은 **[데이터(Fact)]와 [주장(Claim)] 사이의 거리**를 전략적으로 관리하는 것입니다.

**추론의 거리 (Inference Gap)**:
- **거리 0**: 데이터 그 자체 (해석 불필요) → **Show/Demonstrate**
- **거리 1**: 데이터의 직접적 의미 → **Indicate/Reveal**
- **거리 2**: 더 큰 원리/메커니즘에 대한 제안 → **Suggest/Imply**

**💡 핵심 통찰**: Nature/Science는 **Level 3 (Suggest)를 얼마나 세련되게 던지느냐**로 임팩트가 결정됩니다!

### 1.2 3-Level Claim Hierarchy 전략

| Level | 동사 | 역할 | 예시 (fMRI 연구) |
|-------|------|------|------------------|
| **Level 1** | Show, Demonstrate, Reveal | **Defense (신뢰성)** | "Results **show** increased BOLD signal in amygdala" |
| **Level 2** | Indicate, Reflect, Support | **Bridge (연결)** | "This pattern **indicates** fear-processing activation" |
| **Level 3** | Suggest, Imply, Point to | **Attack (임팩트)** | "These findings **suggest** a novel mechanism of threat detection" |

**핵심 전략**: Level 1으로 **탄탄하게 방어**하고, Level 3으로 **과감하게 공격**

### 1.3 Nature/Science Discussion vs 일반 저널 Discussion

| 요소 | 일반 저널 Discussion | Nature/Science Discussion |
|------|-------------------|------------------------|
| **Claim 구조** | Level 1 중심 (사실 나열) | **Level 3 중심** (통찰 제안) |
| **Opening** | "Results show..." | "**These findings suggest** a fundamental..." |
| **범위** | 연구 분야 내 의미 | Cross-disciplinary **implications** |
| **Limitations** | 단순 나열 | Future directions로 전환 |
| **결론** | 요약 반복 | Broader scientific landscape 변화 |

### 1.4 심리학/뇌과학의 위험한 함정: Overclaiming

**❌ 치명적 실수 (Overclaiming)**:
```
"Our results SHOW that subjects felt fear."
→ 데이터는 BOLD 신호일 뿐, '공포'라는 심리상태를 직접 보여준 게 아님
```

**✅ 전략적 접근 (Strategic Claiming)**:
```
"Results SHOW increased BOLD signal in amygdala [Level 1],
which SUGGESTS that fear-processing mechanisms are engaged [Level 3]."
→ 데이터와 해석을 명확히 분리
```

**핵심 원칙**: 심리학/뇌과학은 변인 통제가 어렵기 때문에 **Level 1과 3를 혼동하면 치명적**

**📊 최신 연구 근거 (2024-2025)**:
- **[Inversion Problems](https://www.psychologicalscience.org/news/releases/new-content-from-perspectives-on-psychological-science-2024-october-28.html)**: 연구가 "한 가지를 측정하면서 다른 것을 희망"하는 문제
- **[Stronger Inference 한계](https://direct.mit.edu/jocn/pages/submission-guidelines)**: 기존 관행이 "결과의 견고함은 높이지만 formal한 추론은 지원하지 않음"
- **[Replication Crisis](https://www.thetransmitter.org/community/the-buzziest-neuroscience-papers-of-2023-2024/)**: "진정한 가치가 나타나기까지 다른 그룹들의 재현과 비판 과정 필요"
- **[Inference Generation 연구](https://d-nb.info/137683622X/34)**: 불완전한 정보로부터 추론하는 과정의 복잡성

### 1.2 탑티어 Discussion의 4단계 구조

```
Stage 1: Key Findings (25%)
↓ "What did we discover?"

Stage 2: Theoretical Implications (40%)
↓ "Why does this matter to science?"

Stage 3: Limitations & Future Directions (25%)
↓ "What are the next breakthroughs?"

Stage 4: Broader Impact (10%)
↓ "How does this change the field?"
```

**핵심 원칙**: 각 단계에서 "So what?" 질문에 답하며 점진적으로 impact 확대

## 2. Discussion의 7가지 흔한 실수와 해결책

### 2.1 흔한 실수들

| 실수 | 문제점 | 해결책 |
|-----|-------|--------|
| **Results 재진술** | 새로운 해석 없음 | "What" → "Why" 중심으로 |
| **과도한 겸손** | Impact 축소 | 적극적이되 과장 없는 해석 |
| **Overclaiming** | 데이터 초과 해석 | Evidence-conclusion 엄격한 매칭 |
| **Silo thinking** | 좁은 분야에만 국한 | Cross-disciplinary 연결점 찾기 |
| **Limitation 나열** | 방어적 자세 | 미래 기회로 reframing |
| **약한 결론** | "더 연구 필요" | 구체적 next steps 제시 |
| **Theory 무시** | 현상 기술만 | 기존 이론과의 관계 명시 |

### 2.2 Discussion 성공 패턴 실례 분석

#### Journal of Neuroscience OSAS 논문 Discussion 분석

**논문 예시**: "Cognitive deficits in obstructive sleep apnea: Insights from neuroimaging" (Journal of Neuroscience, 2023)

**❌ 일반적 Discussion 접근**:
```
"Our results showed that OSAS patients had reduced cognitive performance.
This suggests that sleep disruption affects cognition.
Future studies should examine larger samples."
```

**✅ 탑티어 Discussion 접근**:
```
"These findings reveal a fundamental disconnect between traditional
sleep fragmentation theories and the observed pattern of cognitive deficits.
Whereas previous models emphasized REM disruption, our data demonstrate
that intermittent hypoxia during NREM sleep specifically targets
prefrontal-hippocampal connectivity, explaining why working memory
and executive function show disproportionate impairment relative
to basic attention processes."
```

**성공 요소 분석**:
- **Mechanism focus**: 단순 현상 → 구체적 neural pathway
- **Theory challenge**: 기존 REM 중심 이론에 도전
- **Specificity**: "cognitive deficits" → "working memory + executive function"
- **Cross-system integration**: sleep → neurocognitive networks

#### 다른 탑티어 Discussion 패턴

**패턴 1: Mechanism Discovery**
```
"These results reveal the underlying mechanism by which..."
→ 현상을 메커니즘 수준에서 설명
→ 이론적 기여 명확화
```

**패턴 2: Paradigm Challenge**
```
"Our findings challenge the prevailing view that..."
→ 기존 가정에 대한 도전
→ 새로운 관점 제시
```

**패턴 3: Translation Bridge**
```
"These insights provide a foundation for..."
→ 기초연구 → 응용 연결
→ 실용적 의미 부각
```

## 3. Workshop Session (70분)

### Stage 1: Claim Hierarchy Calibration (15분)

**개별 작업**: 3-Level Hierarchy로 주장 강도 조정

**먼저 할 일**: 본인 Discussion 초안에서 동사들을 체크
- "show" "demonstrate" → Level 1 확인: 정말 데이터가 이를 직접 보여주나?
- "suggest" "imply" → Level 3 확인: 추론 거리가 적절한가?

#### 프롬프트 1: Claim Strength Audit
```
내 Discussion 초안의 모든 claim들을 3-Level Hierarchy로 분석해줘:

[Discussion 초안 전문]

각 주요 statement에 대해:
1. **현재 사용한 동사와 claim level 식별**
2. **데이터-주장 매칭도 평가** (overclaiming 위험도)
3. **심리학/뇌과학 특성 고려한 조정 제안**

특히 이런 위험 패턴 체크해줘:
❌ "Results show that participants felt..." (느낌은 직접 측정 안 함)
❌ "fMRI data demonstrate cognitive ability..." (뇌활성=인지능력 직결 위험)
❌ "Our study proves the mechanism..." (prove는 너무 강함)

각 문장을 Level 1 (safe) + Level 3 (impactful) 조합으로 rewrite해줘.
```

#### 프롬프트 2: 핵심 발견 정리
```
내 연구의 핵심 발견들을 Discussion에 적합하게 정리해줘:

연구 배경: [간단히]
주요 결과: [3-5개 bullet points]
연구 분야: [psychology/neuroscience/etc]

다음 형식으로 정리해줘:
1. 가장 중요한 발견 (theoretical breakthrough)
2. 메커니즘 관련 발견 (how/why questions)
3. 실용적 함의 (practical implications)

각 발견에 대해 "So what?"를 한 문장으로 답해줘.

**좋은 예시** (OSAS 연구):
❌ "OSAS 환자들이 인지 저하를 보였다"
✅ "OSAS에서 NREM sleep 중 간헐적 저산소증이 특정적으로 전전두-해마 연결성을 손상시켜, 작업기억과 실행기능의 선택적 결함을 야기한다"

이런 수준의 specificity와 메커니즘 초점으로 정리해줘.
```

#### 프롬프트 2: Discussion 구조 설계
```
내 연구 발견들을 기반으로 Nature급 Discussion 구조를 설계해줘:

핵심 발견들: [위에서 정리한 내용]

4단계 구조로 설계:
1. Key Findings Interpretation (25%): 결과의 의미 해석
2. Theoretical Implications (40%): 이론적 기여와 메커니즘
3. Limitations & Future Directions (25%): 한계를 미래 기회로
4. Broader Impact (10%): cross-disciplinary 영향

각 섹션의 핵심 메시지와 대략적 문단 수를 제시해줘.
```

### Stage 2: Impact Amplifier (15분)

**개별 작업**: Broad significance 발굴

#### 프롬프트 3: Cross-Disciplinary 연결점 발굴
```
내 연구 결과를 다른 분야와 연결시켜 broader impact를 만들어줘:

내 연구: [간단한 설명]
핵심 발견: [주요 결과]

다음 분야들과의 연결점을 찾아줘:
- Clinical psychology/psychiatry
- Cognitive neuroscience
- Educational psychology
- Social psychology
- Technology/AI applications

각 연결점에 대해:
1. 어떤 관련성이 있는가?
2. 어떤 새로운 연구 질문을 열어주는가?
3. 어떤 실용적 응용이 가능한가?

Nature/Science 수준의 broad significance statement 3개를 만들어줘.
```

#### 프롬프트 4: Theoretical Contribution 명확화
```
내 연구가 기존 이론에 어떤 기여를 하는지 명확하게 해줘:

연구 배경: [기존 이론/모델]
내 결과: [핵심 발견]

다음 관점에서 분석해줘:
1. **Theory Extension**: 기존 이론을 어떻게 확장하는가?
2. **Theory Challenge**: 어떤 가정에 도전하는가?
3. **Theory Integration**: 서로 다른 이론들을 어떻게 연결하는가?
4. **New Mechanism**: 어떤 새로운 메커니즘을 제안하는가?

각각에 대해 구체적 evidence와 함께 설명해줘.
```

### Stage 3: Limitation Reframer (10분)

**개별 작업**: 한계점을 미래 기회로 전환

#### 프롬프트 5: 건설적 Limitation 작성
```
내 연구의 한계점들을 미래 연구 기회로 reframe해줘:

연구 방법: [간단히]
주요 한계점: [솔직하게 나열]

각 한계점을 다음 형식으로 전환해줘:

"While our study [한계점을 인정], this limitation opens up exciting opportunities for future research to [구체적 연구 방향]. Specifically, [어떤 연구가 가능한지], which could [potential breakthrough]."

예시:
❌ "Our sample size was limited."
✅ "While our study focused on [specific population], this foundation enables future large-scale investigations to test generalizability across [diverse populations], potentially revealing [새로운 발견 가능성]."

5가지 한계점을 이런 방식으로 전환해줘.
```

### Stage 4: 동료 Discussion 크로스 리뷰 (25분)

## 4. Discussion 섹션 AI 프롬프트 레시피 모음

### 4.1 Claim Hierarchy 캘리브레이션 레시피

#### 레시피 D1: Inference Gap Calibrator
**목적**: 데이터와 주장 사이의 추론 거리를 정확하게 측정하고 적절한 동사 선택
**프롬프트**:
```
내 Discussion 문장들의 claim 강도를 분석하고 적절한 level로 조정해줘:

연구 방법: [간단히]
측정한 데이터: [실제 측정값]
내가 쓴 문장: [분석할 문장들]

각 문장을 다음 기준으로 분석:

1. **Inference Gap 측정**:
   - 거리 0: 데이터 자체 → "show, demonstrate, reveal"
   - 거리 1: 데이터의 직접적 의미 → "indicate, reflect, support"
   - 거리 2: 더 큰 메커니즘/원리 → "suggest, imply, point to"

2. **Overclaiming 체크**:
   - 측정하지 않은 것을 "보여준다"고 주장하는가?
   - 심리적 상태를 생리적 데이터로 "증명"한다고 하는가?

3. **Strategic Rewriting**:
   각 문장을 3-level로 재작성:
   - Level 1 버전 (안전하지만 임팩트 낮음)
   - Level 3 버전 (임팩트 높지만 적절한 겸손함 유지)

**예시**:
❌ "Results show that meditation increases happiness"
✅ "Results show increased activation in reward-related brain regions [L1], suggesting potential mechanisms underlying meditation's effects on wellbeing [L3]"

심리학/뇌과학 특성을 고려해서 각 문장의 claim 강도를 조정해줘.
```
**결과 평가 기준**: 데이터와 주장이 정확히 매칭되고, Level 3 statements가 과장 없이 임팩트 있는가?

#### 레시피 D2: Nature-Style Insight Generator
**목적**: Level 1 facts를 기반으로 Level 3 insights를 전략적으로 생성
**프롬프트**:
```
내 연구의 확실한 팩트들을 기반으로 Nature/Science급 insights를 만들어줘:

확실한 팩트들 (Level 1):
- [데이터 1]: [측정값/통계]
- [데이터 2]: [측정값/통계]
- [데이터 3]: [측정값/통계]

이 팩트들로부터 다음과 같은 Level 3 insights를 제안해줘:

1. **Mechanism Insights**:
   "These patterns suggest..."으로 시작하는 메커니즘 제안
   - 어떤 underlying process가 작동하는가?
   - 왜 이런 패턴이 나타나는가?

2. **Theory Insights**:
   "Our findings point to..."로 시작하는 이론적 함의
   - 기존 이론에 어떤 도전/확장을 제안하는가?
   - 어떤 새로운 관점을 열어주는가?

3. **Translational Insights**:
   "These results imply..."로 시작하는 응용 가능성
   - 다른 분야에 어떤 함의가 있는가?
   - 어떤 practical implications가 가능한가?

각 insight에 대해:
- 왜 이 팩트가 이런 insight를 지지하는지 logical chain 제시
- 어떤 부분이 여전히 speculative한지 명시
- 과장하지 않으면서도 exciting하게 표현

Nature 편집자가 "이거 흥미롭네!"라고 할 만한 Level 3 statements를 만들어줘.
```
**결과 평가 기준**: Level 1 evidence와 논리적으로 연결되면서도 흥미로운 Level 3 insights를 제공하는가?

### 4.2 구조 설계 레시피

#### 레시피 D3: Discussion Blueprint Generator
**목적**: 연구 결과를 4단계 Discussion 구조로 변환
**프롬프트**:
```
내 연구를 Nature급 Discussion 구조로 설계해줘:

연구 요약: [2-3 문장]
핵심 결과: [bullet points]

4단계 blueprint 제작:
1. Key Findings Interpretation (25%)
   - 각 결과의 "what does this mean?" 해석
   - 예상치 못한 결과의 의미

2. Theoretical Implications (40%)
   - 기존 이론과의 관계
   - 새로운 메커니즘 제안
   - Cross-study 일치/불일치 해석

3. Limitations & Future Directions (25%)
   - 각 한계점 → 미래 연구 기회로 전환
   - 구체적 next steps

4. Broader Impact (10%)
   - Cross-disciplinary 함의
   - Practical applications

각 섹션별로 핵심 메시지와 문단 구성을 제시해줘.
```
**결과 평가 기준**: 4단계가 명확히 구분되고, 각 단계가 이전 단계를 기반으로 확장되는가?

#### 레시피 D2: Theoretical Contribution Clarifier
**목적**: 연구의 이론적 기여를 명확하고 구체적으로 표현
**프롬프트**:
```
내 연구의 이론적 기여를 구체화해줘:

기존 이론: [관련 이론/모델]
내 결과: [핵심 발견]
연구 분야: [구체적 subfield]

다음 4가지 관점에서 분석:

1. **Theory Extension**:
   - 기존 이론의 어떤 부분을 확장하는가?
   - 어떤 새로운 요소를 추가하는가?

2. **Theory Refinement**:
   - 어떤 가정을 수정하는가?
   - 어떤 메커니즘을 정교화하는가?

3. **Theory Integration**:
   - 어떤 서로 다른 이론들을 연결하는가?
   - 어떤 갈등을 해결하는가?

4. **Theory Innovation**:
   - 완전히 새로운 무엇을 제안하는가?
   - 어떤 패러다임 shift를 시사하는가?

각 기여에 대해 구체적 evidence와 함께 설명하고, Nature 편집자가 이해할 수 있는 언어로 써줘.
```
**결과 평가 기준**: 이론적 기여가 구체적이고, evidence-based이며, 과장 없이 설득력 있는가?

### 4.2 Impact 확대 레시피

#### 레시피 D3: Cross-Disciplinary Bridge Builder
**목적**: 연구 결과를 다른 분야와 연결하여 broader impact 창출
**프롬프트**:
```
내 연구를 다른 분야와 연결해서 broader scientific impact를 만들어줘:

내 연구: [1-2 문장 요약]
핵심 발견: [주요 결과 3개]
원래 분야: [psychology/neuroscience/etc]

다음 분야들과의 연결점을 찾아줘:
- Clinical applications
- Educational implications
- Technology/AI connections
- Public policy relevance
- Cross-species comparisons (해당시)

각 연결에 대해:
1. **Direct relevance**: 왜 이 분야와 관련 있는가?
2. **Novel insights**: 어떤 새로운 관점을 제공하는가?
3. **Future questions**: 어떤 연구 질문을 열어주는가?
4. **Practical impact**: 어떤 응용이 가능한가?

Nature/Science 수준의 "broader significance" statement 3개를 작성해줘.
예시: "These findings have implications beyond [원래분야], potentially informing [다른분야] through [구체적연결]."
```
**결과 평가 기준**: 연결점이 자연스럽고 설득력 있으며, 과장되지 않았는가?

#### 레시피 D4: Mechanism Spotlight Generator
**목적**: 연구 결과에서 underlying mechanism을 강조하여 깊이 있는 Discussion 작성
**프롬프트**:
```
내 연구 결과에서 underlying mechanism을 부각시켜 깊이 있는 해석을 만들어줘:

연구 설계: [간단히]
주요 결과: [데이터]
관찰된 현상: [what happened]

다음 관점에서 메커니즘을 분석해줘:

1. **Proximate mechanisms**:
   - What: 직접적으로 무엇이 일어났나?
   - How: 어떤 과정을 통해?

2. **Ultimate mechanisms**:
   - Why: 왜 이런 결과가 나타났나?
   - Function: 어떤 기능적 의미?

3. **Cross-level connections**:
   - Micro → Macro: 개별 수준 → 전체 수준
   - 다른 수준의 현상과 어떻게 연결?

4. **Predictive power**:
   - 이 메커니즘으로 무엇을 예측할 수 있나?
   - 어떤 새로운 hypotheses 생성?

각 메커니즘을 evidence와 함께 설명하고, "이것은 단순한 현상 기술이 아니라 깊은 이해"라는 것을 보여줘.
```
**결과 평가 기준**: 현상 기술을 넘어 메커니즘 이해가 드러나며, 예측 가능한 insights를 제공하는가?

### 4.3 Limitation 전환 레시피

#### 레시피 D5: Constructive Limitation Reframer
**목적**: 연구 한계점을 미래 연구 기회와 잠재적 breakthrough로 전환
**프롬프트**:
```
내 연구의 한계점들을 미래 연구의 흥미로운 기회로 reframe해줘:

연구 디자인: [방법론 간단히]
주요 한계점들:
1. [한계점 1]
2. [한계점 2]
3. [한계점 3]

각 한계점을 다음 템플릿으로 전환해줘:

"While our study [한계점을 솔직히 인정], this [제약조건] actually opens up fascinating opportunities for future research to [구체적 연구 방향]. Specifically, [어떤 연구 설계/방법], which could potentially [새로운 발견 가능성] and [theoretical advancement]."

추가 요구사항:
- 방어적 어조 피하기
- "더 연구가 필요하다" 같은 generic statement 금지
- 구체적이고 흥미로운 next steps 제시
- 각 limitation이 실제로는 연구 영역을 확장하는 기회임을 보여주기

5가지 한계점을 모두 이런 방식으로 변환해줘.
```
**결과 평가 기준**: 한계점이 구체적 연구 기회로 전환되고, 방어적이지 않고 건설적인가?

#### 레시피 D6: Future Directions Visionary
**목적**: 현재 연구를 기반으로 흥미롭고 구체적인 future directions 제시
**프롬프트**:
```
내 연구를 기반으로 exciting future research directions을 제시해줘:

현재 연구: [요약]
핵심 발견: [결과]
사용한 방법: [methodology]

다음 5가지 차원에서 future directions 제시:

1. **Methodological advancement**:
   - 어떤 새로운 방법론이 가능할까?
   - 어떤 기술적 breakthrough가 도움될까?

2. **Population extension**:
   - 다른 어떤 집단에서 테스트?
   - Cross-cultural validation?
   - Developmental perspectives?

3. **Mechanistic deepening**:
   - 어떤 underlying process를 더 탐구?
   - Neural/biological mechanisms?

4. **Applied translation**:
   - Clinical applications?
   - Educational interventions?
   - Policy implications?

5. **Theoretical integration**:
   - 다른 이론과의 연결?
   - Cross-disciplinary collaboration?

각 direction에 대해:
- Why exciting: 왜 중요한가?
- How feasible: 실현 가능성은?
- Potential impact: 어떤 breakthrough 가능?

"이런 연구를 하고 싶어질" 만큼 inspiring하게 써줘.
```
**결과 평가 기준**: Future directions가 구체적이고 흥미로우며, 현재 연구와 논리적으로 연결되는가?

### 4.4 품질 검증 레시피

#### 레시피 D7: Discussion Quality Auditor
**목적**: 완성된 Discussion의 탑티어 저널 수준 충족도 평가
**프롬프트**:
```
내가 쓴 Discussion을 Nature/Science 수준으로 평가하고 개선점을 제시해줘:

[Discussion 전체 텍스트]

다음 기준으로 평가 (각 1-10점):

**구조 및 흐름 (25%)**:
- 4단계 구조가 명확한가?
- 논리적 흐름이 자연스러운가?
- 각 문단이 명확한 목적이 있는가?

**이론적 기여 (25%)**:
- 이론적 contribution이 구체적인가?
- 기존 연구와의 관계가 명확한가?
- 새로운 insights가 있는가?

**Broader impact (20%)**:
- Cross-disciplinary 함의가 있는가?
- Practical applications가 현실적인가?
- Scientific community에 의미가 있는가?

**Evidence-conclusion 매칭 (20%)**:
- 주장이 데이터로 뒷받침되는가?
- Overclaiming이 없는가?
- 불확실성을 적절히 인정하는가?

**미래 방향성 (10%)**:
- Limitation이 건설적인가?
- Future directions가 구체적인가?
- 연구 영역을 확장하는가?

각 영역의 점수와 함께 구체적 개선 제안을 해줘:
1. 가장 강한 점 3가지
2. 즉시 개선 가능한 점 3가지
3. Nature 편집자가 거절할 가능성이 있는 부분
4. 전체적인 재작성 제안

최종 점수: __/100점 (Nature/Science 게재 기준)
```
**결과 평가 기준**: 평가가 구체적이고 actionable하며, 탑티어 저널 기준에 부합하는가?

## 5. 평가 기준

### 5.1 Discussion 섹션 완성도 평가

**우수 (A: 90-100점)**
- 4단계 구조가 명확하고 자연스러움
- 이론적 기여가 구체적이고 설득력 있음
- Broader impact가 과장 없이 의미 있음
- Limitation이 미래 기회로 잘 전환됨
- Evidence-conclusion 매칭이 정확함

**양호 (B: 80-89점)**
- 구조가 대체로 명확하나 일부 개선 필요
- 이론적 기여가 있으나 더 구체화 가능
- Impact가 의미 있으나 범위 확장 필요
- Limitation 처리가 적절하나 더 건설적 가능

**보통 (C: 70-79점)**
- 기본 구조는 있으나 논리적 흐름 개선 필요
- 이론적 기여가 모호하거나 피상적
- Impact가 제한적이거나 과장됨
- Limitation이 방어적이거나 generic함

**미흡 (D: 60-69점 이하)**
- 구조가 불분명하거나 results 재진술 수준
- 이론적 기여가 불분명하거나 없음
- Overclaiming 또는 impact 과장
- Limitation을 단순 나열하거나 회피

### 5.2 AI 프롬프트 활용도 평가

**우수**: 다양한 레시피를 창의적으로 조합하여 독창적 Discussion 완성
**양호**: 제공된 레시피를 효과적으로 활용하여 질 높은 Discussion 작성
**보통**: 레시피를 사용했으나 결과물의 질이 아직 부족
**미흡**: 레시피를 제대로 활용하지 못하거나 AI 결과를 무비판적 수용
